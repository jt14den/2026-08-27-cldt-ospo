Prerequisites

  • A GitHub account and a basic working knowledge of Git — your team's lesson repo will live in the UC-OSPO-Network GitHub organization, not personal repos
  • At least one team member has completed Carpentries Instructor Training or Learner-Centered Teaching — already satisfied for this cohort

Pre-Reading (before Thursday)

  • A Primer on Markdown and GitHub — covers the specific web-editing workflow we'll use, worth a skim even if you're already comfortable with GitHub
  • Issue #83 — the lesson's topic and scope as already drafted
  • Choosing a Narrative and Dataset for a Lesson — background for the narrative/use-case work below. Since this isn't a data-analysis lesson, focus on the narrative half rather than dataset selection

Preparing as a Team

This training is designed for a team working together to collaboratively design and develop a new lesson. It helps to meet beforehand and talk through:

  • Who the lesson is aimed at
  • A candidate narrative or use case to hang the licensing content on — we'll lean on the narrative half of the CLDT curriculum's Example Data and Narrative episode Thursday, and each team comes back Friday with a thread to react to

If your schedule allows, set aside some time between Thursday and Friday to follow up together on what we started — not required, but past trainees said the extra time helped.

Your GitHub team access is already set up: everyone's on the licensing-and-copyright team, ready for when the lesson repo itself gets created live on Friday. Reid and Jose, watch for a GitHub org invite if you haven't already accepted one.

The Carpentries Workbench

Lessons in this training are built with The Carpentries Workbench (R packages: sandpaper, varnish, pegboard, tinkr). Install R and RStudio, then run: 

install.packages(c("sandpaper", "varnish", "pegboard", "tinkr"),
    repos = c("https://carpentries.r-universe.dev/", getOption("repos")))
